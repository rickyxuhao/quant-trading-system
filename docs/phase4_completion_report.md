## 一、Phase 4 概述

第四阶段构建完整的 Streamlit 可视化 Dashboard，为量化交易系统提供交互式的策略绩效分析、交易明细展示、模型诊断和参数调优功能。

**核心价值**:
- 将复杂的回测数据转化为直观的可视化图表
- 支持交互式参数调整与实时对比
- 为策略优化提供数据驱动的决策支持

poetry run streamlit run projects/quant_trading/visualization/app.py --server.port 8502

|:---|:---|

### 8.3 使用流程

1. **加载数据**: 点击侧边栏 "📊 加载示例数据"
2. **或运行回测**: 选择策略 → 设置参数 → 点击 "🚀 运行回测"
3. **查看绩效**: 切换 "策略绩效" 页面
4. **分析交易**: 切换 "交易明细" 页面
5. **诊断模型**: 切换 "模型诊断" 页面（ML策略）
6. **优化参数**: 切换 "参数调优" 页面

### 9.2 集成方式

```python
def run_backtest():
    from projects.quant_trading.backtest.engine import BacktestEngine, BacktestConfig

    config = BacktestConfig(
        start_date=start_date,
        end_date=end_date,
        initial_capital=initial_capital,
        benchmark='000300.SH'
    )

    engine = BacktestEngine(config, strategy_instance)
    results = engine.run()

    StateManager.set('backtest_results', results)
```
