# 策略实现计划: ATR自适应动量策略 (ATR-Adaptive Momentum Strategy)

## 1. 策略概述

**策略名称**: ATR自适应动量策略 (ATR-Adaptive Momentum Strategy)
**策略类型**: 趋势跟踪 / 机器学习
**原始论文**: 基于波动率阈值的短期动量策略

**描述**:
该策略基于价格动量效应，使用20日收益率作为动量信号。与传统动量策略不同，它使用ATR（平均真实波幅）作为波动率度量，在高波动期（ATR高于历史均值）降低仓位，在低波动期提高仓位。策略适用于个股和ETF，特别适合震荡上行的市场环境。

## 2. 信号逻辑

### 2.1 入场条件
1. 20日收益率 > 5%
2. ATR14 < 历史20日ATR的90%分位数（低波动环境）
3. 成交量 > 20日均量的1.2倍（确认动量有量能支撑）

### 2.2 出场条件
1. 20日收益率 < -3%
2. 持仓时间 > 10个交易日且当前收益率 < 2%
3. ATR14 > 历史20日ATR的95%分位数（高波动退出）

## 3. 特征变量

| 名称 | 描述 | 计算方法 |
|:---|:---|:---|
| :--- | :--- | :--- |
| momentum_20 | 20日动量 | close / close.shift(20) - 1 |
| atr_14 | 14日ATR | talib.ATR(high, low, close, 14) |
| atr_percentile | ATR分位数 | atr_14在20日历史ATR中的百分位 |
| volume_ratio | 量比 | volume / volume.rolling(20).mean() |
| rsi_14 | 14日RSI | talib.RSI(close, 14) |

## 4. 模型架构

**模型类型**: XGBoost

**关键参数**:
- n_estimators: 100
- max_depth: 5
- learning_rate: 0.1

## 6. 中国市场适配

1. T+1制度：信号在收盘前30分钟生成，次日开盘价执行
2. 涨跌停限制：涨停不追，跌停不杀，增加额外的价格过滤
3. 成本精细化：考虑印花税（卖出收取），高频调仓成本较高
4. 流动性约束：过滤掉日均成交额小于1亿的股票
